An install seed is the drive a new host boots the naru installer with. It tells the host where orch is ({{.SeedOrch}}), which authority to trust there, and an enrollment key made now. The host then shows up under Pending hosts with its hardware and its pairing code.

The key is in the file and nowhere on this page: orch keeps only its hash, so the download is the only copy. Making a seed is logged in orch's events as an enrollment key created by you.
